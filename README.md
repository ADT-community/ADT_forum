# ADT Forum — Open Source Projects for Africa

ADT Forum is a community initiative connected to the [Africa Deep Tech](https://africadeeptech.org) community. Developers, designers and hardware builders from across Africa and the diaspora work together on open source projects that solve African problems, and get paid for their contributions.

## How it works

1. **One project, one Discord channel, one GitHub repo.** Each project has a channel on the ADT Discord for discussion and a repo in the [ADT-community](https://github.com/ADT-community) org for code, issues and decisions.
2. **Anyone can propose a project.** Open an issue in this repo using the *Project proposal* template. Proposals that get community support and a committed maintainer get a channel and a repo.
3. **Open core, real revenue.** Project code is open source. Projects earn money through hosted services, premium features, ads, partnerships or grants.
4. **Contributors get paid.** A share of each project's revenue and grants goes to the people who built it, based on tracked contributions. See [PAYOUTS.md](PAYOUTS.md).
