# ADT Forum — Open Source Projects for Africa

ADT Forum is a community initiative connected to the [Africa Deep Tech](https://africadeeptech.org) community. Developers, designers and hardware builders from across Africa and the diaspora work together on open source projects that solve African problems, and get paid for their contributions.

## How it works

1. **Everything happens on GitHub.** Each project has its own repo in the [ADT-community](https://github.com/ADT-community) org for code and issues, and its own category in [Discussions](https://github.com/orgs/ADT-community/discussions) for conversation. One account, one place, no extra apps.
2. **Anyone can propose a project.** Start a discussion in the **Proposals** category. Proposals that get community support and a committed maintainer get a repo and a discussion category.
3. **Every project is a business.** ADT projects are for-profit. A project may start without revenue, but it must have a clear path to profit, and that is how it is judged. Code is open source (open core); money comes from hosted services, premium features, ads, transaction fees, licensing and partnerships. Grants and prizes help early on but are not a business model.
4. **Contributors get paid.** A share of each project's revenue goes to the people who built it, based on tracked contributions. Early contributors are rewarded once the project earns. See [PAYOUTS.md](PAYOUTS.md).

## Project stages

| Stage | Goal | To move on |
|---|---|---|
| **1. Build** | Ship a first version (MVP) | Real users using it |
| **2. First revenue** | Prove people will pay | Recurring revenue |
| **3. Profit** | Revenue covers costs and contributor payouts | Steady profit |
| **4. Company** | Grow as its own business | Investment or spin-out |

Projects that stall with no path to revenue are paused, so effort goes where it can pay.
